# Assignment 3
This program takes the quiz game from Assignment 1 and turns it into a Flask version, keeping the original mechanics from Assignment 1. At first you'll be asked to select a topic, then once you start, it will pull up the quiz only containing that topic. It also contains the 50/50 system that I had from Assignment 1 and when you make your answer, it will tell you whether its correct or incorrect and will provide an explanation of the correct answer. At the end it will review the questions that you got wrong.
